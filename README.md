# ArtMap Pen Absolute

Клиентский Fabric-мод для **Minecraft Java 26.3**, Windows x64 и One by Wacom
CTL-472-S с официальным драйвером Wacom/WinTab. Преобразует абсолютные координаты
пера в направление камеры по четырём углам холста. Нажим включает обычное действие
Use Item (по умолчанию) или Attack. Сервер получает обычные игровые действия;
устанавливать или изменять что-либо на сервере для этого мода не нужно.

**Экспериментальная альфа.** Автоматическая проверка сборки и геометрии не заменяет
проверку настоящего CTL-472-S и конкретной версии ArtMap. Точное состояние проверок
и процедура приёмки приведены в [TESTING.md](TESTING.md).

## Установка

1. Установите Minecraft Java **26.3**, Fabric Loader **>=0.20.1** и Fabric API **для 26.3**.
2. Установите официальный драйвер Wacom с WinTab для CTL-472-S.
3. Поместите `artmap-pen-absolute-0.2.0-alpha.1.jar` в папку `mods` клиента.
   JNA уже вложена в JAR; Wintab32.dll берётся из установленного драйвера.
4. Подключитесь к своему серверу с работающим ArtMap. Серверная совместимость самого
   ArtMap с версией игры — отдельное условие; мод не обновляет серверный плагин.

## Калибровка и рисование

1. Сядьте у мольберта ArtMap, выберите краситель и оставайтесь неподвижны.
2. Обычной мышью наведите прицел на **центр крайнего верхнего левого пикселя** и нажмите **F6**.
3. Повторите для верхнего правого, нижнего правого, нижнего левого пикселя: **F6 ×4**.
4. После сообщения о готовой калибровке нажмите **F8**, затем приподнимите наконечник.
5. Перемещайте перо над планшетом: положение прицела соответствует абсолютной позиции.
   Коснитесь поверхности, чтобы рисовать; поднимите наконечник, чтобы завершить штрих.
6. **F8** выключает режим и освобождает мышь. **F9** показывает диагностику, **F10** переворачивает Y.

Клавиши переназначаются в настройках управления Minecraft, категория ArtMap.
Для нового холста, изменения его ориентации или позиции игрока выполните калибровку заново.
Калибровка не сохраняется между мирами/подключениями.

При открытии меню или потере фокуса WinTab закрывается и нажатие отпускается.
После возвращения в игру снова поднимите наконечник перед рисованием. При отсутствии
свежих пакетов в течение 500 мс рисование прекращается: при неподвижно удерживаемом
пере для возобновления штриха может потребоваться приподнять его и коснуться снова.

## Настройки

Файл: `.minecraft/config/artmap-pen.json`. Изменения вступают в силу после перезапуска;
F10 сохраняет `flipY` сразу.

```json
{
  "flipY": true,
  "flipX": false,
  "tipButtonMask": 1,
  "pressureThreshold": 1,
  "drawButton": "RIGHT",
  "cancelPhysicalMouseInput": true,
  "sideButton1Mask": 2,
  "sideButton2Mask": 4,
  "sideButton1": "LEFT_CLICK",
  "sideButton2": "NONE",
  "maxEyeMovementBlocks": 0.05
}
```

`drawButton`: `RIGHT` или `LEFT`. Боковые действия: `NONE`, `LEFT_CLICK`, `RIGHT_CLICK`.
Маски кнопок зависят от настроек драйвера; F9 помогает проверить `buttons` и `pressure`.
При смене мира или превышении допуска смещения глаз калибровка сбрасывается.
Некорректные, вырожденные и пересекающиеся углы отклоняются.

## Ограничения

- WinTab работает только на Windows с установленным драйвером; SDL-координаты мыши
  не используются как замена координатам планшета.
- Камера и ввод обновляются с частотой игровых тиков, обычно 20 Гц. Очень короткий
  контакт сохраняется между опросами, но несколько контактов за тик объединяются.
  Быстрые штрихи могут пропускать пиксели; серверные TPS и пинг также влияют на результат.
- Нажим определяет контакт, а не толщину кисти. Боковые кнопки определяются по фронту
  состояния на тике; очень короткое боковое нажатие может быть пропущено.
- Точность зависит от ручной калибровки, положения игрока и реализации ArtMap.
  Мод не содержит автоматического рисования, серверных патчей или нестандартного протокола.

## Сборка

Нужны **JDK 25** и доступ к Maven, Mojang, Fabric и Gradle.

```powershell
.\gradlew.bat --no-daemon clean build
# либо
.\build-windows.ps1
```

На Linux: `./gradlew --no-daemon clean build`.
Gradle Wrapper закреплён на 9.8.0 с SHA-256 дистрибутива, Loom — 1.19.3.
`build` выполняет тесты геометрии, состояния пера, проверку методов Minecraft для
mixin и проверку метаданных/вложенной JNA в конечном JAR.
Результат: `build/libs/artmap-pen-absolute-0.2.0-alpha.1.jar`.

[GitHub Actions](https://github.com/gasada-dev/Minecraft-wacom-integration/actions)
собирает проект на Windows и Ubuntu; версия тега должна совпадать с `mod_version`.
Черновик Release создаётся только после обеих успешных сборок. Подробнее:
[GITHUB_RELEASE.md](GITHUB_RELEASE.md).

## Диагностика

- WinTab недоступен: проверьте официальный драйвер Wacom, затем перезапустите Minecraft.
- Нет координат: F9, профиль приложения в Wacom Center и настройки WinTab/Windows Ink.
- Перепутаны оси: F10 для Y, `flipX` для X, затем новая калибровка.
- Не рисует: приподнимите наконечник, проверьте краситель, режим ArtMap и значения F9.
- Камера или клики дублируются: проверьте `cancelPhysicalMouseInput` и профиль драйвера.
