# Проверки и ручная приёмка

Автоматические задачи запускаются через `./gradlew clean build` (на Windows —
`gradlew.bat`). Тесты падают с ненулевым кодом при нарушении проверяемых условий.

- `testGeometry`: четыре угла, центр, 484 точки перспективной плоскости с переходом
  yaw через ±180°, ограничение координат, отклонение NaN и неправильной геометрии.
- `testPenInput`: старт с нажатым наконечником, короткий контакт между тиками,
  координаты контакта, отсутствие повторного клика, pressure fallback, удержание,
  таймаут 500 мс, proximity/overflow/margin/grab, ограничение координат, WinTab ABI.
- `testMinecraftCompatibility`: наличие точных дескрипторов `MouseHandler.onMove`
  и `onButton` в Minecraft 26.3. Это проверка целей, а не полноценный запуск mixin.
- `verifyModJar`: классы мода, metadata, client environment, точная версия Minecraft,
  версия мода и объявленная вложенная JNA.

GitHub Actions выполняет полную сборку на Ubuntu и Windows. Ссылки на конкретные
прогоны служат подтверждением сборки. Контрольная сумма прилагается к JAR.
Локальная прямая компиляция против официального client.jar 26.3 и три Java self-test
прошли 2026-11-05. Полная локальная сборка в ограниченной среде Codex столкнулась с
отказом Java `Files.isWritable` при создании промежуточного Minecraft JAR; её нельзя
считать успешной на основании прямой компиляции.

## Не выполнено автоматически

- Запуск полноценного Minecraft с применением mixin и загрузкой нативного WinTab.
- Проверка на физическом Wacom CTL-472-S.
- Рисование на настоящем сервере с определённой версией ArtMap.

## Приёмка на Windows с планшетом

1. Записать версии Windows, Wacom Driver, Java, Minecraft, Fabric Loader/API и ArtMap.
2. Установить JAR и Fabric API в клиент. Проверить отсутствие ошибок mixin в latest.log.
3. F8 до калибровки: режим не должен включиться. Отсутствующий драйвер не должен
   приводить к падению игры; должна выводиться диагностика.
4. На мольберте выполнить F6 в порядке TL → TR → BR → BL. Повторить один угол четыре
   раза и записать пересекающиеся углы: оба случая должны отклоняться.
5. После нормальной калибровки включить F8 с прижатым пером: рисования до подъёма
   наконечника быть не должно. Проверить четыре угла и сетку 3×3 в режиме наведения.
6. Нарисовать точку, медленные горизонталь/вертикаль/диагональ, круг; сравнить с мышью.
   Проверить короткое касание и боковую кнопку. Проверить flipY и переназначение клавиш.
7. Во время штриха открыть Escape/инвентарь/чат и сделать Alt+Tab. Действие должно
   отпуститься, клики не должны попадать в меню. После возврата требуется поднять перо.
8. Отключить планшет во время контакта: через 500 мс без пакетов действие отпускается.
   После подключения поднять наконечник и повторить F8 при необходимости.
9. F8 выключает захват; обычная мышь снова работает. Перемещение игрока за допуск,
   выход и повторный вход, смена измерения сбрасывают калибровку.
10. Сохранить latest.log, F9-диагностику и результат. До этого совместимость с
    физическим планшетом и ArtMap остаётся неподтверждённой.
